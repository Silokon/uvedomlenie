Как обновить образец заполнения

Образец, который сотрудники видят на экране «Образец», берётся из файла obrazec.xlsx, лежащего рядом с программой на GitHub. Чтобы изменить образец, достаточно заменить этот файл. Программу трогать не нужно.

1. Подготовьте новый образец

  1. Скачайте текущий файл: откройте страницу репозитория, нажмите на obrazec.xlsx, затем кнопку «Download raw file» (значок со стрелкой вниз).
  2. Откройте его в Excel и внесите изменения. Буквы ставятся по одной в квадрат, как обычно. Цвет букв можно любой, на экране он сохранится.
  3. Сохраните файл под тем же именем obrazec.xlsx в формате Excel (.xlsx).

2. Загрузите файл на GitHub

  1. Войдите в свой аккаунт GitHub с компьютера или телефона.
  2. Откройте страницу репозитория с программой.
  3. Нажмите кнопку «Add file» (справа над списком файлов), затем «Upload files».
  4. Перетащите новый obrazec.xlsx в область загрузки или выберите его кнопкой «choose your files». Имя файла должно быть точно таким же, тогда старый файл заменится.
  5. Внизу страницы нажмите зелёную кнопку «Commit changes».
Через 1-2 минуты образец обновится у всех. Если на телефоне по-прежнему виден старый образец, закройте вкладку с программой и откройте её заново.

Что важно

  • Заменяйте только obrazec.xlsx. Файл index.html это сама программа, его менять не нужно.
  • Не переименовывайте файл и не меняйте названия листов внутри него.
  • Данные, которые сотрудники вводят в форму, на GitHub не попадают: заполнение идёт в браузере, на сервер ничего не отправляется.
